# 社区招募文案

我们在做一个“微信 ClawBot 本机 AI 路由器”，想邀请感兴趣的朋友一起实现。

设想很简单：在微信里给 ClawBot 发任务，注册电脑上的路由器调用已安装、已登录的 AI 工具。某个工具额度用完或暂时不可用时，在确认可以安全重试后切换到另一个，结果仍回到微信。

目标是 macOS 和 Windows，通过 CLI、ACP 或专用桌面客户端适配器接入，路由器不直接调用 AI 厂商模型 API。

目前有中文项目大纲和早期 CLI 原型，尚未完成端到端验证。我们希望先做通两个真实 CLI，再完善任务状态、会话隔离、取消和故障恢复，逐步探索桌面客户端。

欢迎参与 CLI/ACP 适配、Windows/macOS 进程管理、ClawBot 接入、桌面自动化可行性研究或中文文档。一个适配器、一份错误样例、一项平台验证都很有帮助。可以在项目 Issue 里写下你想认领的方向和手边的系统环境。

许可证待项目所有者确定，当前先征集设计反馈与研究结论。发布时请附上本项目仓库链接。
