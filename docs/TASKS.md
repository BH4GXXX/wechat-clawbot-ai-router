# 待认领任务

以下任务尚未在 GitHub 创建为 Issue。建议发布后按编号逐项建单。P0 应先于适配范围扩张完成。

| 编号 | 优先级 | 任务 | 交付与验收条件 |
| --- | --- | --- | --- |
| T01 | P0 | 确认电脑端入口与 OpenClaw 插件契约 | 记录实际版本和配置；微信发出任务、收到本机执行结果；失败和取消能返回明确状态 |
| T02 | P0 | 修正错误分类与安全回退 | 区分启动失败、额度拒绝、任务执行失败和未知状态；普通回复包含错误关键词时不误切换；执行中断不重复执行任务 |
| T03 | P0 | 消息去重与任务状态 | 定义 request/session ID、排队、运行、完成、失败、未知状态；重复消息不重复执行；不同会话不串上下文 |
| T04 | P1 | 首批真实 CLI 适配器 | 至少两个已登录 CLI；提供明确版本和平台记录、输出解析、额度/登录失败样例及可用配置 |
| T05 | P1 | Windows 进程生命周期 | 覆盖路径空格、命令发现、取消和超时；子进程及后代进程不残留；提供实际验证记录 |
| T06 | P1 | macOS 后台环境 | 说明后台 PATH、工作目录、登录和重启行为；后台启动后能完成同样的微信任务 |
| T07 | P1 | 健康状态与冷却 | 错误脱敏、可配置恢复策略；并发不破坏状态；全部不可用时明确说明原因 |
| T08 | P2 | ACP 适配与会话隔离 | 初始化、创建/恢复会话、流式结果、权限请求、取消、进程崩溃与闲置回收均有明确处理 |
| T09 | P2 | 桌面客户端可行性矩阵 | 分别研究 DeepSeek、豆包、WorkBuddy、ChatGPT、Claude；给出有来源的入口、版本、平台、限制，不把厂商名称等同于已支持 |
| T10 | P2 | 桌面客户端首个适配器 | 基于 T09 选一个客户端；能识别输入、完成、错误状态；应对窗口焦点变化和用户同时操作；说明权限与版本 |
| T11 | P2 | 中文安装与诊断体验 | 用户能分辨未安装、未登录、额度不足和通道断开；提供可脱敏的诊断信息 |
| T12 | 发布前 | 许可证与社区设置 | 所有者确认许可证；补充授权文件；开启 Issues/Discussions；将任务拆为可认领 Issue |

建议首批贡献从 T04 的单个适配器、T09 的单个客户端研究或 T11 的文档开始。认领时填写系统、版本、范围和验收方案。
